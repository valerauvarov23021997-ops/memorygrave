# Ассеты для сторов

Материалы для карточек App Store и Google Play.

## Скриншоты

`screenshots/` — 5 маркетинговых скриншотов в размере **1290×2796**
(iPhone 6.7", подходит и для Google Play):

| Файл | Экран | Заголовок |
|------|-------|-----------|
| `01-search.png` | Поиск | Найдите место памяти близких |
| `02-grave.png` | Страница памяти | Всё о родном человеке |
| `03-catalog.png` | Каталог услуг | Закажите уход в пару касаний |
| `04-candle.png` | Свеча памяти + книга | Зажгите свечу памяти |
| `05-report.png` | Фотоотчёт | Фотоотчёт о каждой работе |

Это маркетинговые макеты экранов в фирменном стиле «Warm Minimal»
(не скриншоты сборки). Данные — реалистичные, обезличенные.

### Требования сторов

- **App Store:** нужны размеры 6.7" (1290×2796) — эти файлы подходят.
  Дополнительно можно добавить 6.5" (1242×2688). Минимум 3 скриншота.
- **Google Play:** телефонные скриншоты 9:16, минимум 2. Эти подходят.

### Как перегенерировать

Скриншоты собираются программно (HTML → Chromium через Playwright):

```bash
cd docs/store-assets
mkdir -p out
node screenshots-gen.js   # положит png в ./out
```

Требует `playwright-core` и установленный Chromium. Правьте заголовки,
данные и стили прямо в `screenshots-gen.js`.

## Видео-превью для карточки

`Pamyat-AppStore-Preview.mp4` — 886×1920, H.264, **60 fps**, 30 сек,
со звуком: женская русская озвучка + фоновая эмбиент-музыка.
Формат подходит для App Store (превью 6.5–6.7") и Google Play.

Один непрерывный кадр без склеек и стоп-кадров: камера плавно
облетает телефон в 3D-пространстве — от кинетического открытия
(«Они далеко. / Память — рядом.») через сплэш, поиск имени,
свечу памяти и фотоотчёт к финальной заставке с логотипом.
Внутри рамки — запись живого приложения (web-эмуляция).

Как собрано (детерминированный покадровый рендер):
1. `preview-take.js` — съёмка дубля приложения в Chromium (webm),
   затем ffmpeg нарезает его в PNG-кадры 25 fps (`app-frames/`).
2. `preview-render60.js` — виртуальный таймлайн на кейфреймах
   (позиция камеры, повороты, титры, кадр приложения) рендерит
   1800 кадров 60 fps через Playwright: `preview` — контрольные
   стилы, `full` — весь хронометраж.
3. Озвучка — edge-tts (`ru-RU-SvetlanaNeural`), музыка — синтез
   (арпеджио + пад, Am–F–C–G). Сведение и H.264 — ffmpeg
   (`loudnorm I=-16`, музыка ≈ −10 дБ под голосом).
