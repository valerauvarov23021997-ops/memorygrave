# Видео «Память» — исходники

Ролик 1:55, 1920×1080, 30 к/с. Без закадрового голоса: текст на экране и музыка.

**Текущая версия — v3** (`film3.html`, `film3.js`, `music3.py`): кинематографичный моушн-дизайн в тёмной гамме —
живой фон из света и тумана, боке, плёночное зерно и виньетка; текст появляется по буквам из расфокуса;
объёмный телефон с толщиной и бликом, камера наезжает на детали интерфейса; веер экранов в 3D;
план Даймища «лежит» в пространстве. Музыка — монотонный эмбиент без отдельных нот и ударов.
Версии v1 и v2 (`film.*`, `film2.*`, `music.py`, `music2.py`) оставлены для истории.

| Файл | Что делает |
|---|---|
| `takes.js` | Записывает 6 дублей живого приложения (веб-сборки клиента и исполнителя на демо-данных) через CDP-скринкаст |
| `plot.js` | Рисует стилизованные иллюстрации «до/после» для демо-фотоотчёта (это не фото) |
| `film.html` | Все сцены ролика; `render(t)` рисует кадр на момент `t` секунд |
| `film.js` | Покадровый рендер `film.html` в MP4 (`node film.js render out.mp4`, превью — `node film.js preview 5,50`) |
| `music.py` | Синтез фоновой музыки с нуля (пэд, фортепиано, бас, зал) — прав третьих лиц нет |

Сборка: `node takes.js` → `node film3.js render film3-video.mp4` → `python3 music3.py` (нужен scipy) →
`ffmpeg -i film3-video.mp4 -i music3.wav -af "highpass=f=40,lowpass=f=7500,loudnorm=I=-16:TP=-1.5" -c:v copy -c:a aac -b:a 192k -shortest Память-видео.mp4`.

Пути в скриптах указывают на рабочую папку сессии — при пересборке их надо поправить.
Нужны: веб-сборки клиента (порт 8111) и исполнителя (8110) в мок-режиме, `ffmpeg`, Chromium.

Честность: данные в приложении — демонстрационные; план кладбища Даймище — реальная съёмка.
