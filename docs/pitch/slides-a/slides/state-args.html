Зачем это государству

Шесть выгод для государства

Задача закрыта

Инвентаризация кладбищ и реестры мест захоронений — по единому стандарту во всех регионах.

Данные для Госуслуг

Наполнение федеральной платформы «Управление захоронениями» и НСПД.

Доход кладбищ

80 % каждого заказа — кладбищу. По модели — около 0,65 млрд ₽ на третий год.

Обеление рынка

Договор и оплата после фотоотчёта вместо «бригад по объявлению». Видимые обороты и налоги.

Память и воспитание

Учёт и уход за воинскими захоронениями, проекты со школами и поисковыми отрядами.

Картина по стране

Заполненность кладбищ, свободные места, заброшенные могилы — в одной системе.

Шесть конкретных выгод для государства. Первое — задача закрыта. Инвентаризация кладбищ и реестры мест захоронений появляются во всех регионах, причём по единому стандарту, а не так, как получилось у каждого подрядчика. Второе — данные для Госуслуг. Мы наполняем данными федеральную платформу «Управление захоронениями» и Национальную систему пространственных данных. Без данных платформа остаётся витриной. Третье — доход кладбищ. 80 процентов каждого заказа получает кладбище. По нашей модели на третий год это около 650 миллионов рублей по стране — за работу, которую сейчас либо никто не делает, либо делают бригады по объявлению. Четвёртое — обеление рынка. Договор, оплата после фотоотчёта, видимые обороты и налоги. Пятое — память и патриотическое воспитание. Тот же инструмент подходит для учёта воинских захоронений и ухода за ними, для проектов со школами и поисковыми отрядами. И шестое — картина по стране. Где кладбища переполнены, где есть свободные места, сколько заброшенных могил — впервые в одной системе.
