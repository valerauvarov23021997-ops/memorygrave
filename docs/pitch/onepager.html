Предложение о государственно-частном партнёрстве · ноябрь 2026

Память

Единый цифровой реестр захоронений и честный сервис ухода за ними — по всей России

Учредители безвозмездно передают государству 50–60 % компании. Взамен — ИТ-концессия (115-ФЗ, гл. 4.1), под которую банк финансирует развитие. Средства бюджета не требуются.

Проблема

  • В России более 73 000 кладбищ; федеральный сервис «Управление захоронениями» охватит данными 14 000.
  • Инвентаризация кладбищ и реестры мест захоронений рекомендованы регионам до 31.12.2025 — срок прошёл.
  • Уход за захоронениями — преимущественно теневой рынок: наличные, без договоров и чеков.

Решение

  • Оцифровка кладбищ: план с точностью 1–3 м, фото памятников, имена. Реестр — бесплатно для муниципалитетов, данные — для Госуслуг и НСПД.
  • Приложение для семей: найти захоронение, заказать уход из любого города, фотоотчёт, оплата после результата.
  • Работы выполняют администрации кладбищ и получают 80 % стоимости заказа.

Уже сделано

  • Кладбище д. Даймище (Ленинградская обл.) оцифровано полностью: 382 места, 375 имён, точность 1–3 м, затраты не более 100 тыс. ₽.
  • Приложение для семей и для кладбищ работает на реальной базе данных; путь «заказ → работа → фотоотчёт» проверен.

Что получает государство

  • Решённую задачу по реестрам — по единому стандарту во всех регионах.
  • Данные для «Управления захоронениями» и НСПД.
  • Систему и данные в собственности, контрольную долю в компании.
  • Обеление рынка: каждый заказ — с договором, чеком и фотоотчётом.
  • Ноль рублей бюджета — на создание и на ведение реестра.

Просим

  1. Поручить профильному ведомству проработать ИТ-концессию на национальную систему учёта мест захоронений.
  2. Определить уполномоченную государственную организацию для получения доли.
  3. Поддержать пилот в 3–5 регионах с интеграцией в «Управление захоронениями» и НСПД.
