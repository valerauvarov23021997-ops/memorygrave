Решение

  • План кладбища с точностью 1–3 м
  • Фото каждого памятника
  • Имена и даты — в базе

Семьям

  • Найти могилу по фамилии
  • Заказать уход из любого города
  • Оплата после фотоотчёта

Кладбищам

  • Заказы выполняет администрация
  • 80 % каждого заказа — им
  • Без фото «до/после» не закрыть
