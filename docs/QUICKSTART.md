# QUICKSTART — первые шаги агента

Ты Claude Code. Вот твой алгоритм на старте:

1. Прочитал `CLAUDE.md`? Хорошо.
2. Открой `docs/PROGRESS.md`.
3. Найди первую задачу `TODO` (сейчас это `00-setup`).
4. Открой `tasks/00-setup.md`, прочитай целиком.
5. Реализуй по шагам. Пиши реальный код.
6. Прогони: `yarn tsc --noEmit && yarn eslint .`
7. Обнови `docs/PROGRESS.md`: статус → DONE, впиши резюме и дату.
8. Коммит: `chore(setup): инициализация проекта`.
9. Переходи к `01-design-system`.

Работай автономно. Спрашивай только про секретные ключи или юридические/денежные решения.
