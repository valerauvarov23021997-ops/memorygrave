# 🚀 Выпуск в App Store и Google Play

Пошаговая инструкция по сборке и публикации приложения **«Память»** через **EAS**
(Expo Application Services). Сейчас приложение работает на моках
(`EXPO_PUBLIC_USE_MOCKS=true`), поэтому его уже можно собрать и загрузить в сторы
как рабочую демо-версию — без готового бэкенда.

> Всё выполняется **на твоём компьютере** (Windows/Mac), где стоят Node и Git.
> Из облака сборку запустить нельзя — нужны твои аккаунты Apple/Google.

---

## Быстрое тестирование без сторов (Expo Go)

Дать приложение тестеру, который **не в твоей Wi-Fi-сети**, можно двумя способами.

### Туннель — пока запущен твой компьютер

```bash
npx expo start --tunnel
```

QR-код из терминала работает через интернет: тестер сканирует его в Expo Go
из любой точки мира. Медленнее локальной сети и живёт, пока запущен сервер.

### EAS Update — ссылка живёт сама (рекомендуется)

```bash
# один раз: привязка проекта (после eas login)
cd apps/client
eas update:configure

# публикация — повторять после каждого изменения
eas update --branch preview --message "что изменилось"
```

В консоли появится ссылка на страницу обновления на expo.dev — там QR-код.
Тестер сканирует его в Expo Go и получает актуальную версию; твой компьютер
может быть выключен. `expo-updates` и `runtimeVersion: sdkVersion` уже
прописаны в проекте.

> После `eas update:configure` в `app.config.ts` появится `projectId` —
> закоммить и запушь это изменение.

## 1. Установка инструментов (один раз)

```bash
npm install -g eas-cli
eas login          # войти в аккаунт Expo
```

---

## 2. Инициализация проекта в EAS (один раз)

Из папки приложения:

```bash
cd apps/client
eas init           # создаст projectId и пропишет его в app.config
```

Повтори то же для исполнительского приложения, если будешь публиковать и его:

```bash
cd apps/executor
eas init
```

---

## 3. Сборка

### iOS (App Store)

```bash
cd apps/client
eas build --platform ios --profile production
```

EAS сам предложит создать сертификаты и provisioning-профиль — соглашайся
(нужен вход в Apple Developer). На выходе — файл `.ipa` в облаке.

### Android (Google Play)

```bash
cd apps/client
eas build --platform android --profile production
```

На выходе — `.aab` (Android App Bundle), именно его требует Google Play.

> Хочешь быстро проверить на своём телефоне без сторов — собери `preview`:
> `eas build --platform android --profile preview` даст `.apk`, который
> ставится напрямую по ссылке.

---

## 4. Публикация

### App Store

1. Создай приложение в [App Store Connect](https://appstoreconnect.apple.com)
   с bundle ID **`app.pamyat.client`**.
2. Впиши в `apps/client/eas.json` → `submit.production.ios` свои данные
   (`appleId`, `ascAppId`, `appleTeamId`) вместо заглушек.
3. Загрузка:
   ```bash
   eas submit --platform ios --profile production
   ```

### Google Play

1. Создай приложение в [Google Play Console](https://play.google.com/console)
   с package **`app.pamyat.client`**.
2. Скачай JSON сервисного аккаунта, положи его в `apps/client/google-play-key.json`
   (файл уже в `.gitignore` — в репозиторий не попадёт).
3. Загрузка:
   ```bash
   eas submit --platform android --profile production
   ```

## 5. Метаданные для карточки в сторе

Готовые тексты на русском — копируй в App Store Connect / Play Console.

**Название:** Память — уход за захоронениями

**Подзаголовок (iOS, до 30 симв.):** Забота на расстоянии

**Краткое описание (Google, до 80 симв.):**
Уход за могилами близких с фотоотчётом, где бы вы ни находились.

**Полное описание:**
```
«Память» — сервис ухода за захоронениями для тех, чьи близкие покоятся
в другом городе.

• Найдите захоронение по имени или на карте
• Закажите уборку, цветы, реставрацию памятника или скамейку
• Получите фотоотчёт о каждой выполненной работе
• Зажгите виртуальную свечу памяти и соберите книгу воспоминаний
• Пригласите родных к совместному уходу
• Настройте напоминания о памятных датах

Мы создали «Память», чтобы забота о близких не прерывалась расстоянием.
Тепло, спокойствие и уважение — в каждой детали.
```

**Ключевые слова (iOS):** память, уход, могила, кладбище, уборка, захоронение, цветы

**Категория:** Стиль жизни (Lifestyle)

**Возрастной рейтинг:** 4+

**Политика конфиденциальности и условия:** готовые тексты — `docs/PRIVACY.md`
и `docs/TERMS.md`, а готовые к хостингу страницы — `docs/privacy.html` и
`docs/terms.html`. Залейте их на сайт (например, `pamyat.app/privacy` и
`pamyat.app/terms`) и укажите URL политики в карточке стора. Обе ссылки уже
подключены в приложении (Профиль → Помощь) через `apps/client/src/lib/links.ts` —
поменяйте там адреса, если хостинг будет другим. Перед публикацией замените
контакты Оператора (`privacy@pamyat.app`, `support@pamyat.app`) и реквизиты
на актуальные.

## Примечание про моки

Сборки собираются с `EXPO_PUBLIC_USE_MOCKS=true` — приложение полностью
рабочее на демо-данных: вход по любому SMS-коду, тестовые захоронения,
имитация оплаты. Когда будет готов бэкенд, поменяйте флаг на `false`
и укажите реальный `EXPO_PUBLIC_API_URL` в `env` профиля `production`
в `eas.json`, затем пересоберите.
